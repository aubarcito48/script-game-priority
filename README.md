# Scripts de Prioridad en Windows

Este proyecto incluye dos automatizaciones para ajustar prioridad de procesos:

- PrioridadAlta: sube la prioridad de juegos para darles preferencia de CPU.
- PrioridadBaja: baja la prioridad de apps en segundo plano para liberar recursos.

Uso rapido:
1. Ejecuta el iniciador correspondiente como administrador.
2. Usa el script de prueba para ver mensajes en consola.
3. Usa el script de detener para finalizar el proceso cuando quieras.
